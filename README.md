# 🐾 猫娘语录集

> 卡拉彼丘 · 喵言喵语收藏所

一个用来收藏和复制《卡拉彼丘》相关语录的小网页。
点一下卡片,就把语录复制到剪贴板 —— 方便往游戏大厅、群里粘贴喵。

**🔗 直接打开:https://dudy211.github.io/Strinova-quotes/**

---

## 怎么用

| 操作 | 效果 |
|---|---|
| **左键点卡片** | 复制这句语录,卡片会变绿并提示「复制成功喵 :3」 |
| **点带 `擦边` 角标的卡片** | 第一次点先**揭开**模糊遮罩,再点一次才复制 |
| **顶部搜索框** | 模糊搜索,正文和角色标签都能搜。输入「猫语录」也能命中「猫娘语录集」 |
| **顶部角色标签** | 点一下只看这个角色的语录,再点一次取消 |
| **卡片上的 `#角色名`** | 同样可以点,直接筛选该角色 |
| **右下角 🎲 随机一条** | 随机抽一句;旁边的开关决定**是否可能抽到擦边语录** |
| **右上角 🌙 / ☀️** | 切换深色 / 浅色,选择会被记住 |

搜索框里按 `Enter` 立即搜索,按 `Esc` 清空。

## 语录怎么来的

所有语录都放在仓库的 **`quotes/quotes.txt`** 里,纯文本,谁都能改。

格式很简单:**一行一条语录**,紧跟的那行如果是 `#` 开头,就是它的标签行。

```
排位需慢打,心急则掉分。这局我就先挂机了...

香奈美的内裤收到了喵,好吃喵!谢谢喵!
#1#香奈美#星绘

大厅竟然没人复制粘贴了喵
```

- `#1` → 标记这句是**擦边**(页面上会先模糊遮罩)
- `#香奈美` `#星绘` → **角色标签**,想写几个写几个
- 两行之间空不空行都行,纯为好看
- 语录本身**不能以 `#` 开头**(会被当成标签行)

想加新语录?在 GitHub 网页上点开 `quotes/quotes.txt` → 右上角铅笔图标 → 照着格式加 → 提交就行。

## 关于

- 纯静态页面,没有后端,打开就能用

- 想改**配色 / 圆角 / 字号** → `css/variables.css`(深色浅色两套都在里面)
- 想改**标题 / 副标题** → `js/config.js` 顶部
